# Lint, Russian

Run `python3 lint/lint.py FILE --lang ru`, then check by eye:

- «Не просто X, а Y» и «это не X, это Y»: не больше одной антитезы на текст, лучше ни одной.
- Тройки ради ритма («быстро, просто и надёжно»).
- Деепричастный хвост, который объясняет смысл («…, подчёркивая важность…»), и «это значит / это показывает».
- Штампы: «погрузитесь», «откройте для себя», «в мире, где», «давайте разберёмся», «стоит отметить», «важно понимать».
- Раздувание значимости: «играет ключевую роль», «настоящий прорыв», «уникальный».
- Канцелярит вместо глагола: «осуществлять проведение» → «проводить», «является» → «это».
- Длинное тире в русском тексте допустимо, в английском нет.
- Тест переносимости: подошло бы предложение другому человеку без изменений? Тогда в нём нет информации.
